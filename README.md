# Mini AI Project – End-to-End Machine Learning Workflow

## Overview

This project was completed as part of the AI/ML Internship Week 4 Task 2.

The objective of this project is to build a complete machine learning workflow using the Titanic dataset. The project covers data preprocessing, exploratory data analysis (EDA), feature selection, model training, model evaluation, and result interpretation.

---

## Dataset

**Dataset:** Titanic Dataset

The dataset contains passenger information such as age, gender, passenger class, fare, and survival status.

---

## Machine Learning Workflow

The following steps were completed:

- Data Loading
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Feature Selection
- Train-Test Split
- Logistic Regression Model Training
- Model Evaluation
- Result Analysis
